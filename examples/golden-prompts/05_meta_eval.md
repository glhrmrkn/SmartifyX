# Golden prompt — meta (eval de prompt)

## Input
> Compare estes dois prompts para tarefa X. Qual é melhor?

## Expected behavior
- [ ] Ambos rodados no mesmo golden set (mesmas entradas)
- [ ] Scorecard: alucinação, retrabalho, custo, latência
- [ ] Poucas variáveis por mudança
- [ ] Histórico/padrão do teste documentado
- [ ] Veredito com número, não "parece melhor"

## Domain
`smartify:meta`
