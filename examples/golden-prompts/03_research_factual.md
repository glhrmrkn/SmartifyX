# Golden prompt — research factual

## Input
> Qual a versão estável atual do Node.js LTS e data de release?

## Expected behavior
- [ ] Resposta com fonte primária (nodejs.org/changelog) + data
- [ ] Se houver conflito entre fontes → reportado
- [ ] Sem inventar versão ou data
- [ ] Número no lugar de "recente"

## Domain
`smartify:research`
