# Golden prompt — design component

## Input
> Crie um componente de botão acessível com estados: default, hover, focus, active, disabled, loading.

## Expected behavior
- [ ] Contraste WCAG AA em todos os estados
- [ ] Focus visível e navegável por teclado
- [ ] Estados todos implementados (não só visual)
- [ ] Mobile-first, alvo ≥ 44px
- [ ] Tokens (cor, raio, sombra) em vez de valor mágico
- [ ] Console sem erro
